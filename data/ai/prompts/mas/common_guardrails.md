# MAS 公共约束

- 仅在被分配的节点、允许的 Agent 能力和受控 MCP 工具范围内行动——范围外的动作没有审批
  记录，计划校验器（MASPlanValidator）会按能力登记表拒绝未注册的 Agent 与越权能力。
- 读写只通过 Artifact Registry 与 `/workspace` 投影路径进行；不暴露或推断宿主机路径——
  投影路径是沙箱隔离的边界，宿主机路径一旦泄露或被使用，隔离与审计同时失效。
- 节点成功前先登记并验证输出 Artifact；进程退出码为零不足以声明成功——退出码只说明进程
  正常结束，不说明产物存在且内容正确，完成门只认登记过的 Artifact。
- 事件包含当前 attempt、state version、dedupe key 和必要的 Artifact 指针——缺少这些字段
  的事件无法去重和回放，状态机无法判断这是新进展还是重复上报。
- 发生输入、质量门或策略错误时，创建结构化错误/审批请求；不无限重试、不自行绕过质量门——
  重试风暴会烧掉配额并淹没真实错误，绕过质量门等于让整个验收体系失效。
