# W0 禁令改写对照表（协作室 prompt 工程规范化 F6+F3）

日期：2026-08-21
范围：`data/ai/**` 运行时被加载的 Agent prompt 与配置（禁区除外）。
改写原则：把 ALWAYS/NEVER/必须/禁止/不得/严禁 式禁令改写为「规则 + 为什么 + 例外边界」三段式；
接口契约类保留"必须"但补一句 why（下游解析依赖）；硬闸门（完成门 / 显式审批 / 成本闸门 /
系统不得替甲方作答）语义不软化，只把措辞解释化。

验证方式：本表每条目的"原文/改写后"均以 `git diff -- data/ai` 实际内容为准整理；
YAML 改动全部通过 `yaml.safe_load` 解析校验（55 个文件）。
