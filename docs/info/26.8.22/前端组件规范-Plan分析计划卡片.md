# 前端组件规范：Plan 分析计划卡片（PlanCard）

> 规范版本：v1.0（2026-08-22）
> 适用范围：AI 工作台对话页 · Plan 模式"分析计划"卡片；同为输入框附着型卡片的组件（如 AskUser 澄清卡片）可参照本规范的容器与动效条款
> 技术栈约定：Vue3 + Pinia + SCSS 变量体系（--chat-* / --neutral-* / --shadow-*）
> 来源：2026-08-22 Plan 卡片视觉与交互优化迭代的规范化沉淀，对应施工文档《分析计划卡片视觉与交互优化实现计划》

---

## 1. 组件定义

PlanCard 是 Plan 模式下渲染在对话区、用于展示任务步骤列表与执行进度的卡片组件。

**组件定位：输入框附着面板（Composer-attached Panel）**。它不是一条普通消息，而是输入区的延伸——应与底部输入框构成一个视觉整体，表示"当前正在为你执行的工作"。

## 2. 设计原则

| 原则 | 含义 |
|---|---|
| 等宽对齐 | 卡片左右边界与底部输入框像素级对齐，纵轴统一 |
| 附着成组 | 卡片与输入框视觉成组，但保持独立容器，不做连体结构 |
| 可折叠 | 长内容默认可收起为一行摘要，不霸屏 |
| 状态清晰 | 进行中 / 待执行 / 已完成三态一眼可辨，进度量化 |
| 令牌优先 | 颜色、阴影一律使用 CSS 变量令牌，禁止硬编码色值 |

---

## 3. 解剖结构（Anatomy）

```
┌──────────────────────────────────────────────┐
│ ① 标题行                                      │
│   [标题 分析计划]  [② 进度 chip 2/7]  [③ 折叠] │
├──────────────────────────────────────────────┤
│ ④ 步骤列表（纵向时间线）                       │
│   ◉──── 步骤文字（进行中）            进行中   │
│   │                                          │
│   ○──── 步骤文字（待执行）            待执行   │
│   │                                          │
│   ✓──── 步骤文字（已完成）            已完成   │
└──────────────────────────────────────────────┘
        ↑ 与输入框间距 8px，左右边界对齐
┌──────────────────────────────────────────────┐
│ 输入框                                        │
└──────────────────────────────────────────────┘
```

| 编号 | 元素 | 说明 |
|---|---|---|
| ① | 标题行 | 整行可点击，触发折叠/展开 |
| ② | 进度 chip | 量化进度 "X/N"，替代"N 个步骤"纯文字 |
| ③ | 折叠按钮 | chevron 图标，随状态旋转 |
| ④ | 步骤列表 | 时间线节点 + 连接线 + 步骤文字 + 右侧状态标签 |

**折叠态**只保留标题行，内容替换为单行摘要（见 §7.2）。

## 4. 布局规范

| 条目 | 规范值 |
|---|---|
| 宽度 | 与底部输入框**完全相同的限宽约束**（同一 wrapper 或相同 max-width + 水平 padding），左右边界像素级对齐 |
| 与输入框间距 | 8px |
| 卡片圆角 | 12px；与输入框圆角同族（输入框 16px 时卡片取 12px） |
| 嵌套圆角规则 | 内层元素圆角 = 外层圆角 − 内外间距（如外 12px + 间距 4px → 内 8px） |
| 容器边框 | 1px 实线，浅色主题 rgba(0,0,0,0.06~0.08)，使用 --neutral-* 令牌 |
| 容器背景 | var(--chat-ai-card) 或等价令牌 |
| 容器投影 | var(--chat-shadow-sm)；无该令牌时用 0 1px 2px rgba(0,0,0,0.04), 0 4px 12px rgba(0,0,0,0.04) |
| 响应式 | 各断点下保持与输入框对齐；移动端禁止出现横向滚动 |

**禁止事项**：
- 禁止卡片横向铺满消息列而与输入框错位；
- 禁止"卡片叠进输入框"的连体结构（遮挡输入区、耦合两个组件生命周期）；
- 禁止无容器样式（无描边/无背景/无投影）的裸文本形态。

---

## 5. 尺寸与间距

| 元素 | 规范值 |
|---|---|
| 标题 | 字号 14px / 字重 600 |
| 步骤文字 | 字号 13~14px；当前（进行中）步骤字重 500，其余 400 |
| 步骤行 padding | 8px 12px |
| 状态标签 | 右对齐，与步骤文字同行 |
| 时间线连接线 | 宽 2px，颜色 rgba(0,0,0,0.08)（浅色主题） |
| 时间线节点 | 与步骤文字**首行基线对齐** |
| 折叠按钮 | 24×24px，圆角 6px，hover 底色 rgba(0,0,0,0.04) |
| 进度 chip | 字号 12px，圆角 999px（胶囊形），水平 padding 8px |

## 6. 色彩规范（状态色体系）

颜色一律使用令牌；下表给出语义映射与浅色主题参考值，深色主题使用对应 --chat-* / --neutral-* 变量，**文字对比度不低于 WCAG AA（4.5:1）**。

| 状态 | 节点视觉 | 文字/标签 | 参考值（浅色） |
|---|---|---|---|
| 进行中 | 实心圆点 + 外环 box-shadow: 0 0 0 3px color-mix(in srgb, var(--chat-accent) 15%, transparent) | var(--chat-accent) | 平台主蓝色系 |
| 待执行 | 空心圆点（灰描边） | --neutral-text-3，**不得浅于 #98a2b3** | ≥ 4.5:1 对比度 |
| 已完成 | 实心 ✓ 对勾 | --neutral-text-2 | 次要文字色 |
| 进度 chip | — | 文字 var(--chat-accent)，背景 color-mix(in srgb, var(--chat-accent) 12%, transparent) | 主色 12%  tinted |

**禁止事项**：
- 禁止新造色值绕过令牌体系；
- 禁止"待执行"使用低于 4.5:1 对比度的浅灰；
- 禁止深色主题下直接复用浅色主题的 rgba 描边而不验证观感。

## 7. 交互规范

### 7.1 折叠 / 展开

- 触发区域：**标题行整行可点击**，折叠按钮（chevron）为辅助触发点；
- chevron 随状态旋转 180°，过渡 200ms；
- 折叠按钮需带语义：`aria-expanded` 随状态切换，`aria-label` 为"折叠计划/展开计划"；可点击区域不小于 24×24px。

### 7.2 折叠态摘要格式

| 场景 | 摘要文案 |
|---|---|
| 执行中 | 「分析计划 · 已完成 X/N · 当前：{当前步骤标题}」（标题过长 ellipsis 截断） |
| 全部完成 | 「分析计划 · N/N 已完成 ✓」 |

### 7.3 自动折叠规则

- 计划**全部完成后自动折叠一次**，收起为完成态摘要；
- 用户手动展开后，**不再自动折叠**（用户意图优先于自动行为）；
- 折叠状态在会话内保持（组件级 state 即可，不要求持久化）。

## 8. 动效规范

| 动效 | 参数 |
|---|---|
| 折叠/展开高度过渡 | grid-template-rows: 0fr ↔ 1fr（不支持时降级 max-height），250ms ease-out |
| chevron 旋转 | 180°，200ms |
| 进行中节点呼吸脉动 | opacity 1 ↔ 0.3，周期 1.2s，ease-in-out，仅使用 opacity |
| 通用约束 | 所有动画只用 transform / opacity / box-shadow；过渡 200~300ms；循环动画周期 1~1.4s |
| 降级 | `prefers-reduced-motion: reduce` 时取消全部动画，折叠/展开直接切换 |

## 9. 响应式与无障碍

- 移动端保持与输入框对齐，不出现横向滚动；
- 全部文字对比度 ≥ 4.5:1（WCAG AA），深浅双主题各自验证；
- 折叠状态对屏幕阅读器可感知（aria-expanded + 摘要文本包含进度信息）；
- 动画遵守 prefers-reduced-motion 降级条款（§8）。

## 10. Do / Don't

| ✅ Do | ❌ Don't |
|---|---|
| 卡片与输入框等宽、间距 8px、视觉成组 | 卡片铺满消息列、与输入框错位 |
| 独立卡片容器（描边 + 圆角 + 背景 + 柔和投影） | 连体结构，卡片叠进输入框 |
| 折叠摘要携带进度与当前步骤信息 | 折叠后只剩标题，信息全丢 |
| 全部完成后自动折叠一次 | 每次状态更新都自动折叠，打扰用户 |
| 颜色全部走 --chat-* / --neutral-* 令牌 | 组件内硬编码 hex 色值 |
| 进度用 "X/N" chip 量化 | "N 个步骤"静态文字，无进度感 |

## 11. 复用与关联

- 本规范的**容器条款**（§4 布局、§6 状态色之外的容器色、§8 动效）适用于一切输入框附着型卡片；AskUser 澄清卡片的容器与高亮规范（《AskUser澄清卡片视觉优化实现计划》）与本规范同源，后续应统一收敛为"附着卡片通用容器"基类样式；
- 施工落地与验收流程见《分析计划卡片视觉与交互优化实现计划》；
- 本规范变更需同步更新施工文档，避免口径漂移。
