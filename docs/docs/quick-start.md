# 快速开始

本指南帮助您在 5 分钟内启动第一个分析任务。

## 前置条件

- 已完成 CygnusX 部署
- 拥有有效账户并已登录
- 已准备样本 FASTQ 文件

## 步骤一：准备样本

进入「数据管理」页面，上传样本数据。支持的格式包括：

- `*.fastq.gz`
- `*.fq.gz`

## 步骤二：选择分析流程

进入「分析流程中心」，选择您需要的流程，例如：

- **RNA-seq 差异表达分析**
- **ATAC-seq 染色质可及性分析**

## 步骤三：填写参数

根据页面表单填写：

- 项目信息
- 参考基因组
- 样本分组
- 对比组合

## 步骤四：提交任务

点击「提交任务」按钮，系统将自动创建 Snakemake 工作目录并启动分析。

## 步骤五：查看结果

进入「任务中心」，点击任务名称查看：

- 实时日志
- 任务进度
- DAG 可视化
- 结果文件

恭喜，您已完成第一个 CygnusX 分析任务！
