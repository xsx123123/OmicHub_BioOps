# API/MCP 接口数量统计报告

> 统计日期：2026-09-22 · 统计基线：main 分支工作区（含未提交改动）· 验证方式：运行中实例 `app.openapi()` 实测 + 源码逐项核对

## 总计数

| 类别 | 数量 |
|---|---|
| REST 接口（计入） | **569** |
| WebSocket 接口（计入） | **8** |
| MCP 工具（计入，代码可枚举） | **131** |
| **合计** | **708** |

## 统计口径

1. 只统计主链路接口：登录/认证、项目、任务、文件、对话、AI 助手、技能/Agent、交付物等对外功能接口。
2. 只统计"已完成且已投入使用"的接口：路由注册、有实际处理逻辑、非 stub/TODO/placeholder。
3. 排除项：
   - 框架自动生成的文档接口（`/docs`、`/openapi.json`、`/redoc`、`/docs/oauth2-redirect`）；
   - 纯健康检查/监控端点（`GET /health`、`GET /metrics`），单独列示不计入；
   - 内部控制端点（`/studio/internal/*` 3 个，`include_in_schema=False`，控制 token 鉴权）；
   - debug 模式顶层重定向（`/flows`、`/flows/{path}`）；
   - 标注 `deprecated=True` 的向后兼容端点（`GET /files/workspace`、`GET /files/tree`）。
4. MCP 工具与 REST 接口分开统计，逐个列出 tool 名称并验证绑定执行函数非空壳。

## 统计路径

- 后端为 FastAPI（`src/cygnusx/main.py`），所有业务路由经 `src/cygnusx/api/v1/router.py:68-158` 挂载到 `/api/v1`（含 `register_tool_routers` 自动发现 8 个生信工具子包）。
- MCP 工具来源：builtin 预设（`src/cygnusx/infrastructure/mcp/presets.py`、`pipeline_preset.py`）+ 动态工具箱预设（`tool_configs/tools_schema.yaml`）+ stdio 外部 server（conda-meta-mcp）。

## 交叉验证

- 在运行中的 web 容器内用 `app.openapi()` 拉取真实路由表：**570 ops / 492 paths，零重复端点**（`(method, path)` Counter 全部唯一）。
- 42 个动态工具逐个 import 验证 `service.method` 绑定真实存在（42/42 通过）。
- builtin MCP 58 个工具 handler 逐个确认非空壳；抽查 `_platform_sandbox_execute`（presets.py:140-175）为真实沙盒执行逻辑。
- 全仓 TODO/stub 扫描：仅命中 `users.py:236` 一处注释（RBAC 待完善，但该端点有真实逻辑）；8 处 `pass` 均为 WebSocket 断连异常处理，非空实现。
- studio.py 的 `/sessions/{id}/share` 三个路由分别是 POST/GET/DELETE，方法不同不构成重复。

## 排除清单

| 接口 | 排除原因 |
|---|---|
| `/docs`、`/openapi.json`、`/redoc`、`/docs/oauth2-redirect` | 框架自动生成文档接口（main.py:362-363，仅 debug 模式） |
| `GET /health`（main.py:478） | 纯健康检查，按要求单独列示不计入 |
| `GET /metrics`（telemetry mount） | Prometheus 监控端点，纯监控 |
| `POST /studio/internal/sessions/{id}/exec`（studio.py:269）、`POST /studio/internal/recycle-idle`（studio.py:293）、`DELETE /studio/internal/sessions/{id}/workspace`（studio.py:305） | 内部控制端点，`include_in_schema=False`，非对外功能接口 |
| `GET /flows`、`GET /flows/{path}`（main.py:469-474） | debug 模式顶层重定向，非功能接口 |
| `GET /files/workspace`、`GET /files/tree`（files.py:197,220） | 标注 `deprecated=True`，已由 `/files?source=` 替代（有真实逻辑，如需可计入 +3） |

注：`src/cygnusx/api/v1/docs.py` 的 `/api/v1/docs/*`（17 个）**未排除**——它是业务"知识库文档"模块（CRUD+审核+issues），非框架文档接口，已计入。

## 不确定项

| 接口 | 需要什么信息才能判定 |
|---|---|
| conda-meta-mcp 的 ~5 个工具（package_search/import_mapping/pypi_to_conda/repoquery/file_path_search） | 工具清单由外部 `cmm` 进程运行时发现（mcp_service.py:404-455），代码无法静态枚举；需查 DB `mcp_servers.tools` 快照确认当前实际数量 |
| MCP Builder 用户自建实验 MCP 的工具 | 存 DB、随用户构建动态产生（mcp_builder_service.py:502），数量取决于运行时数据；材料中建议不计入或注明"动态" |
| 用户侧 vs 管理侧拆分比例 | 汇总表功能域为近似归类（admin/* 127 个整体列示）；若材料要求"用户可见接口数"，需再按前端调用面过滤 |

## 给材料填数的建议

口径最硬的数字：**REST+WS 577 个、MCP 工具 131 个（另含 conda-meta-mcp 约 5 个 stdio 工具）、合计约 708 个**——全部经运行中实例 openapi 实测与逐个 handler 验证，可经得起追问。
