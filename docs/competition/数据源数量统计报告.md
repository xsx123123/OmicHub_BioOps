# 平台材料 · 数据源数量统计报告

> 统计日期：2026-09-22
> 统计范围：OmicHub 仓库主链路（代码、配置、初始化脚本中被真实加载/下载/查询/索引的数据来源）
> 结论：主链路实际接入并投入使用的数据源共 **11 个**

---

## 统计路径

数据接入有 5 条链路，全部已核实：

1. **参考基因组注册表** `refdata/reference_genomes.yaml`（`.env` 覆盖为 `/data/omichub/omichub_data/reference/reference_genomes.yaml`，由 `src/cygnusx/reference_genomes/config.py:121` 加载，indexer 构建 SQLite FTS5 索引）；
2. **工具配置** `tool_configs/`（富集 `enrichments/species_config.yaml`、JBrowse `jbrowse/jbrowse_config.yaml`、BLAST `blast/blast_db.yaml`）；
3. **外部 API 直连**（文献检索、UniProt/KEGG REST）；
4. **知识库向量库**（`kb_documents`/`kb_chunks` + pgvector，启动时从 `docs/knowledge/meta.yaml` 引导，`src/cygnusx/main.py:223`）；
5. **分析管线参考基因组** `pipelines/*/config/reference.yaml`。

所有"在盘文件"均在 web 容器内实际验证过挂载可见。
