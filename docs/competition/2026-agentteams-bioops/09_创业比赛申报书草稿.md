## 一、项目背景意义

**写法要点**：痛点（行业）→ 现有方案为什么不行 → 本项目切入点 → 政策/趋势背书。控制在 3~4 段。

生命科学正进入"多组学驱动"时代，药物研发、种业育种、医学检验、科研服务等机构每天都要交付大量 RNA-seq、ATAC-seq、单细胞等分析项目。但一次组学分析交付横跨数据接收、元数据核验、流程执行、质量控制、报告交付等多个角色，目前普遍依赖人工在聊天工具、表格、脚本和任务系统之间传递信息，存在四类突出问题：

1. **任务链路断裂**：样本表、分组信息、参考基因组版本分散，缺失问题往往到计算后期才暴露，造成算力和工期浪费；
2. **责任与权限混杂**：研究人员、分析工程师、质控人员共享高权限入口，无法界定"谁批准、谁提交、谁放行"；
3. **结果难以复核**：交付物往往只有一个压缩包，参数、质量指标、失败重试记录不完整，科研可重复性无从谈起；
4. **经验无法复用**：同类项目每次都从零沟通，无法沉淀为可复用的流程模板和质量规则。

与此同时，大模型 Agent 技术虽然火热，但"对话式 AI 助手"无法直接进入科研生产环境——让 LLM 直接操作服务器、随意执行命令在数据安全和质量合规上不可接受。市场缺少的是一个把 AI 协同能力装进"有身份、有权限、有审批、有证据"框架里的交付系统。

本项目 CygnusX BioOps 以自主研发的多组学分析平台 CygnusX 为执行底座，构建多 Agent 协同（AgentTeams）的可信交付基础设施：把"研究人员提需求—分析人员跑流程—质控人员签字—项目经理交付"组织为可审批、可恢复、可验证、可审计的闭环。项目契合《"十四五"生物经济发展规划》、AI for Science 国家战略方向，为生命科学研发机构提供从"零散 AI Demo"走向"可运营生产系统"的关键一环。

## 二、项目实施内容

**写法要点**：分模块写，每个模块一句话"做什么 + 已有基础 + 比赛期做什么"。突出"不是从零开始"。

1. **多组学分析执行底座（已基本建成）**：基于 FastAPI + Vue3 + PostgreSQL + Celery + Snakemake 的私有化平台，覆盖 RNA-seq/ATAC-seq 等流程的提交、监控、结果工作台，后端 227 个 Python 模块、严格 DDD 四层架构。
2. **多 Agent 协同层（核心实施内容）**：复用已有通用协调 Agent 与 RNA-seq/ATAC-seq/单细胞领域 Agent，新增数据预检（Data Steward）、质量审计（Quality Auditor）、交付报告（Delivery Reporter）三个专职 Agent，组成 BioOps 工作组；将一次自然语言需求拆解为"Case → 工作项 → Skill 调用 → 产物 → 质量决策 → 证据 → 交付清单"的结构化闭环。
3. **受控工具体系**：把预检、流程提交、监控、取消、质量门、交付打包等动作沉淀为带输入输出契约、幂等键、失败语义和权限边界的 Skill；Agent 不拥有 shell、数据库或流程文件写权限，高风险动作需人工审批令牌。
4. **证据与审计系统**：全链路统一 trace 字段，产物以逻辑引用 + 校验摘要登记入 Artifact Registry，质量规则版本化管理，关键事件持久化可回放，支持交付后的完整复核。
5. **示范场景与模板沉淀**：以 bulk RNA-seq 差异分析交付为示范 Case 打通端到端链路，并将"受控任务交付"模式抽象为可配置模板，向 ATAC-seq、单细胞、药物筛选、临床报告审核等场景迁移。

## 五、预期贡献及验收指标

**写法要点**：贡献分"行业/技术/社会"三条；验收指标务必可量化、可第三方核验，与业务价值表对齐。

### 预期贡献

1. **行业贡献**：为生命科学研发机构提供首套"可审计多 Agent 组学交付"基础设施，把 AI 协同从演示玩具变为可运营生产工具；
2. **技术贡献**：形成"受控任务交付 Case"模式与配套的 Agent 身份、Skill 契约、证据审计规范，可迁移至任意高价值科学计算场景；
3. **社会贡献**：提升科研结果可重复性与数据安全性，降低中小型生物企业的数字化门槛，助力农业育种与生物医药自主创新。

### 验收指标（比赛结束时核验）

- **功能**：端到端完成 ≥3 条示范链路（成功交付/预检阻断/人工复核），演示可重复执行；
- **质量**：首次预检阻断率、质量门首次通过率、人工复核率可统计导出；未授权高风险调用数为 0；
- **审计**：任一交付 Case 可从证据事件完整回放，交付清单缺失时系统自动阻断；
- **工程**：提供一键部署包、样例数据、自动化测试，新环境部署到跑通 ≤【X】小时；
- **复用**：发布 ≥【3】套行业模板，新增一种分析模态接入时间 ≤【X】人日。
