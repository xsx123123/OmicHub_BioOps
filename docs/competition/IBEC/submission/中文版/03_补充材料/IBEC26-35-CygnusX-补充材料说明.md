## 3. 建议提供的证据

1. **实机截图包。** 至少包含任务分派、预检、分析计划、结果交付、代码/日志视图、证据包列表。截图应脱敏，且附一句说明“CygnusX 为项目平台的开发代号”（如界面仍显示旧名称）。
2. **完整交付证据包。** 包含交付 README、环境快照、软件版本清单、参数、结果表、图表、MD5SUMS 与 `verification.tsv`。
3. **三条演示链路。** 正常通过、预检阻断、质量门转人工复核；每条至少有截图或录屏和输入输出说明。
4. **使用证明。** 若项目报告声明“已投入使用”，应提供华中农业大学园艺林学学院基因组学实验室的签字/盖章证明或可追溯试用反馈。
5. **受控访问方式。** 可提供只读演示账号或视频，不得将生产环境口令直接写入材料。

## 4. 运行环境与复现说明

- 操作系统：建议 Ubuntu 22.04+；分析流程以容器化环境执行。
- 平台：Python 3.11+、FastAPI、SQLAlchemy、Vue 3、PostgreSQL（含 pgvector）、Redis；具体锁定依赖以仓库中的 `pyproject.toml`、`uv.lock` 与 `frontend/package.json` 为准。
- 流程：RNAFlow/Snakemake 等经审核流程资产；请在每个结果包中注明流程版本、镜像版本、参考基因组与注释版本。
- 硬件：平台服务建议 8 核 CPU、16 GB 内存起；实际测序数据运行资源随物种、样本量和流程不同而变化。
