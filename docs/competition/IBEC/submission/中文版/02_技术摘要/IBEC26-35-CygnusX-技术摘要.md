## P03｜核心方法学：认知推理与确定性内核解耦（核心壁垒）

> **本页结论（Action Title）：首创"AI 负责科学规划，专家资产负责物理计算"的双引擎解耦架构**

```text
【上层：科研认知与规划层】（AI 自由度）
  科学假说输入 ➔ 意图解构 ➔ 18 位专职 Agent 协同 ➔ 假说拓扑规划
                    ↕  声明式能力契约 + 动态质量门
【底层：确定性科学计算底座】（可复现、严谨）
  专家验证工作流 (Snakemake) ➔ 38 项原子科学 Skill ➔ 容器镜像沙盒 ➔ 全自动证据胶囊
```

三大科学设计原则：

1. **能力边界受控**：Agent 只做语义路由、假说拆解与生物学解释；无 shell、无流程 YAML、无数据库写权限，不随机构造代码。
2. **契约化科学技能**：38 项原子 Skill 严密固化统计学假设（如生物学重复 $N \ge 3$）与输入前置条件（如禁输 FPKM/TPM）。
3. **独立同行评审机制**：质量审计 Agent 拥有独立阻断权；质控异常或规则缺失即中断并转人工，绝不由模型自行放行。

## P04｜系统矩阵：科学多智能体协同与可复算凭证

> **本页结论（Action Title）：18 位专职科研 Agent ＋ 全生命周期证据胶囊，构建闭环研究体系**

左右分栏：

**左栏：18 位多智能体科研协同矩阵**

- *分析专家域*：转录组、表观调控、变异挖掘、单细胞时空组学 Agent 等 9 位；
- *科研治理域*：质量审计员（把关 Q30 / Mapping Rate / 混杂因子）、数据管理员（把关参考基因组与注释版本匹配）、科学交付报告员；
- *通用与工程域*：意图解析、实验规划、编程、可视化、开发、运维等。

**右栏：Provenance Capsule 四大要素**

- **环境快照**：锁定 Docker / Singularity 镜像哈希与 Conda Lockfile；
- **数据因果图**：遵循 W3C PROV 规范，追踪从原始 FASTQ 到最终图表的数学变换历程；
- **产物指纹**：全要素 MD5 校验表，逐文件输出 `SUCCESS / MISSING / FAIL / ERROR` 机器自验状态；
- **复算凭据**：随包输出 `reproduce_experiment.sh`，断网环境下一键重跑。

*工程规模：覆盖用户、权限、流程、任务、文件、AI 对话等 29 个应用服务，后端 227 个 Python 模块。*

## P05｜科研实证：植物抗病防御多组学靶点挖掘

> **本页结论（Action Title）：从自然语言科学假说直达高置信度候选调控靶标，赋能真实科研突破**

**真实案例场景**："探讨植物受病原真菌侵染 24 小时后，由 WRKY 家族转录因子调控且染色质开放度协同增加的核心防御基因。"

端到端推演（时间轴呈现）：

1. **假说拆解**：规划 Agent 自动构筑"RNA-seq 差异表达 ＋ ATAC-seq 启动子开放区 ＋ W-box 基序扫描"双组学计算图谱；
2. **严苛质控**：审计 Agent 实时把关，Mapping Rate 达 89.2%、TSS 富集得分 9.8，全绿通过质量门；
3. **因果证据收敛**：从全基因组 35,000+ 基因中，逐层过滤至 12 个核心高置信候选基因（启动子开放度倍数 > 2.1 且转录显著激活）；
4. **成果输出**：自动交付含可交互染色质轨道图、级联调控网络解释与完整可复算证据胶囊的科研论证报告。

```text
35,000+ 基因 ─➔ 840 差异表达 ─➔ 86 启动子开放度协同 ─➔ 12 个 W-box 核心靶基因
```

## 附：答辩演讲实用 Tips

1. **开场 1 分钟抓牢评委**："各位老师好，AI 浪潮下很多人试图用大模型直接写代码做生信，但在座各位专家都清楚：生信分析最怕'代码能跑通，结果全幻觉'。CygnusX 的核心理念就是**绝不让大模型盲目生成代码**，而是让它成为懂实验设计的军师，去调动专家审核过的严谨管线。"
2. **讲 P05 案例时突出华农特色**：用植物/作物抗病调控这类真实生物学问题，切忌再提"146 个基因"这类模拟数据结果，让评委感受到团队真正懂生物学痛点。
3. **应对"大模型不写代码，智能体价值在哪"的质辩**：落脚点在**科学实验规划（Planning）、多组学证据共定位（Causal Evidence Reasoning）与运行时主动质控干预（Auditing）**——这才是科学家真正耗费心力的地方，底层命令只是体力活。
