# RNA-seq 分析

RNA-seq 是转录组研究最常用的技术之一。

## 样本设计

- 每个处理组至少 3 个生物学重复
- 尽量控制批次效应
- 记录样本处理方式、测序批次等元信息

## 参考基因组

| 物种 | 版本 |
|---|---|
| 人类 | `hg38` |
| 小鼠 | `mm10` |
| 拟南芥 | `TAIR10` |

## 差异分析工具

| 工具 | 适用场景 |
|---|---|
| `DESeq2` | count 数据，稳健性强 |
| `edgeR` | 小样本或复杂设计 |

## 质量控制

1. 检查 FastQC 报告中的 per-base quality
2. 关注 rRNA 残留比例
3. 确认比对率 > 70%

## 结果解读

差异表达结果关键列：

| 列名 | 含义 |
|---|---|
| `gene_id` | 基因 ID |
| `baseMean` | 平均表达量 |
| `log2FoldChange` | 差异倍数 |
| `padj` | 校正后的 p 值 |

建议阈值：`padj < 0.05` 且 `|log2FoldChange| > 1`。
