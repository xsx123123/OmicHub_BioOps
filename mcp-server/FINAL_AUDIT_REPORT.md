### 1. 添加完整的参数说明 (`:param`)
每个工具都包含详细的参数说明：
- 参数名称
- 参数类型和格式
- 实际示例值（如 `'GSE151530'`, `'running'`）

### 2. 添加返回说明 (`:return`)
明确说明返回数据的格式和内容结构。

### 3. 添加使用示例 (`示例:`)
提供可执行的调用示例代码：
```python

```

### 4. 统一返回格式
所有工具遵循统一的返回格式：
```json
{

}
```

## 📝 Docstring 规范标准

每个工具的 docstring 应包含以下要素：

```python
"""[功能描述]

:param param_name: 参数说明（如:'example_value'）
:param another_param: 另一个参数说明
:return: JSON 格式的返回内容说明

示例:
    await function_name("example")
    # 返回预期结果
"""
```

**必需元素**:
- ✅ 功能描述
- ✅ 参数说明 (`:param`)
- ✅ 返回说明 (`:return`)
- ✅ 使用示例 (`示例:`)
