## 📝 附录：Docstring 规范标准

每个工具的 docstring 应包含以下要素：

```python
"""[功能描述]

:param param_name: 参数说明（如:'example_value'）
:param another_param: 另一个参数说明
:return: JSON 格式的返回内容说明

Example:
    await function_name("example")
    # 返回预期结果
"""
```

**必需元素**:
- ✅ 功能描述
- ✅ 参数说明 (`:param`)
- ✅ 返回说明 (`:return`)
- ✅ 使用示例 (`Example:`)

**可选元素**:
- 注意事项
- 错误处理说明
- 相关工具链接
