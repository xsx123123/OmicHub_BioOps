## Introduce
### DEG_Annotation_reference
本文件夹为单细胞差异分析结果注释reference文件夹，`FindMarkers_Celltype_group.r` 脚本的`DEG_annotation`函数会自动引用该注释文件对差异分析结果进行自动注释。（PS:该注释数据集也可以bulkRNA-seq & 蛋白组等不同组学的差异分析结果进行注释）
### gene.info
```bash
hg19_Homo_sapiens.gene_info # hg19 gene annotation info
hg38_Homo_sapiens.gene_info # hg38 gene annotation info
mm10_Mus_musculus.gene_info # mm10 gene annotation info
```
