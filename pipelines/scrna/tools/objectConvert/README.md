# RDS Format Conversion Module

## Overview
The RDS Format Conversion Module provides comprehensive tools for converting between various single-cell data formats, with a focus on RDS (R data serialization) format which is widely used in the Seurat ecosystem.

## Components

### 1. RDS_convert - Format Converter
Converts between different single-cell data formats:
- Seurat RDS ↔ AnnData H5AD
- Seurat RDS ↔ Loom
- Seurat RDS ↔ SingleCellExperiment (SCE)
- Seurat RDS → MTX + Barcodes + Features

#### Usage:
```bash
# Convert Seurat RDS to AnnData H5AD
RDS_convert -i input.rds -o output.h5ad

# Convert AnnData H5AD to Seurat RDS
RDS_convert -i input.h5ad -o output.rds

# Convert to Loom format
RDS_convert -i input.rds -o output.loom

# Convert to SingleCellExperiment
RDS_convert -i input.rds -o output.sce
```

#### Parameters:
- `-i, --input`: Input file path (supports: .rds, .h5ad, .loom, .sce, .h5, .hdf5)
- `-o, --output`: Output file path (with appropriate extension)
- `-f, --format`: Specify output format if auto-detection fails (rds, h5ad, loom, sce, mtx)
- `-c, --conda-env`: Conda environment path for python dependencies
- `-s, --seurat-version`: Seurat object version (4.0, 5.0; default: 5.0)
- `-h, --help`: Show help message

### 2. RDS_utility - RDS Operations
Provides specialized operations for RDS files:
- **info**: Display information about RDS file contents
- **subset**: Extract subset of cells based on cell type or cluster
- **merge**: Merge multiple RDS files into one
- **optimize**: Optimize RDS file size and structure
- **extract**: Extract specific components (expression matrix, metadata)

#### Usage:
```bash
# Get information about an RDS file
RDS_utility -i input.rds -p info

# Subset RDS by cell type
RDS_utility -i input.rds -o subset.rds -p subset -c "T cells"

# Subset RDS by cluster
RDS_utility -i input.rds -o subset.rds -p subset -l "0,1,2"

# Filter by metadata
RDS_utility -i input.rds -o filtered.rds -p subset -m "treatment" -v "control"

# Optimize RDS file size
RDS_utility -i input.rds -o optimized.rds -p optimize

# Extract components to CSV files
RDS_utility -i input.rds -o extracted_dir -p extract
```

#### Parameters:
- `-i, --input`: Input RDS file path
- `-o, --output`: Output RDS file path (for operations that save files)
- `-p, --operation`: Operation to perform (info, subset, merge, optimize, extract)
- `-c, --cell-type`: Cell type for subsetting (for subset operation)
- `-l, --cluster`: Cluster ID for subsetting (for subset operation)
- `-m, --metadata`: Metadata column name for filtering
- `-v, --metadata-value`: Metadata value for filtering
- `-h, --help`: Show help message

## Integration with Pipeline

The RDS conversion module integrates seamlessly with your existing scRNA-seq analysis pipeline:

1. **Input compatibility**: Works with the RDS files generated by your pipeline (e.g., scrna_seq.rds, scrna_seq_final.rds)
2. **Output compatibility**: Can generate RDS files that are compatible with downstream analysis steps
3. **Logging**: Uses the same log4r logging system as the rest of your pipeline
4. **Parameter parsing**: Uses the same getopt parameter parsing as other tools

## Dependencies

The RDS conversion module requires the following R packages:
- Seurat
- sceasy (for AnnData conversion)
- loomR (for Loom conversion)
- reticulate (for Python integration)
- SeuratDisk (for MTX conversion)

Python dependencies (for AnnData conversion):
- scanpy
- anndata

## Use Cases

1. **Cross-platform compatibility**: Convert your Seurat objects to formats compatible with other tools (AnnData for Python-based analysis)
2. **Data sharing**: Export your processed data in standard formats for collaborators
3. **Downstream analysis**: Convert to formats required by specialized analysis tools
4. **Storage optimization**: Use the utility tools to optimize RDS file size
5. **Subset analysis**: Extract specific cell populations for focused analysis
